# MalmegaVille Sentinel

MalmegaVille Sentinel is a defensive Windows desktop security platform for personal endpoint protection.

## Architecture

- Desktop Agent: C# + .NET 8, Windows Service, local encrypted cache
- Backend: Node.js + Express, JWT, REST API, WebSocket
- Database: MongoDB
- Frontend: React + TypeScript + Tailwind CSS
- Notifications: Telegram, Email

## Phases

1. Project structure
2. Backend, authentication, MongoDB, Telegram alerts
3. System monitoring, USB monitoring, timeline, dashboard
4. Threat detection, incident reports, cloud backup, restore
5. AI analysis, threat scoring, forensics, advanced analytics
